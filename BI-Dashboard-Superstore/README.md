# Week 2: Business Intelligence Dashboard — Superstore Retail Analysis

## Overview
This project simulates a Junior BI Analyst engagement for a national retail 
company, using Microsoft Power BI to build an executive dashboard analyzing 
sales, profit, regional performance, and customer behavior.

## Dataset
Superstore Sales Dataset (9,994 records) — Kaggle

## Tools Used
- Microsoft Power BI (Power Query, DAX measures, interactive dashboard)
- Microsoft Excel (initial data inspection)

## Key Findings
- West region leads in both sales and profit
- Central region shows a sales-to-profit efficiency gap
- Furniture generates high sales but disproportionately low profit
- Sales peak sharply in September, dip lowest in February

## Deliverables
- BI Overview Report
- Executive Summary
- Business Insights, Risks & Recommendations
- Power BI Dashboard (.pbix)
- Dashboard Export (PDF)

## Skills Developed
Power Query data cleaning, DAX measures, data visualization, 
business insight generation, executive reporting
